# Python 台股監控小程式

一套使用 Python + PyQt6 開發的 Windows 台股監控桌面程式。可以查詢上市、上櫃股票行情，管理多份持股清單，並自動計算損益、發出價格提醒，以及把最新股價寫回 Excel。

> 本專案以個人學習與實務自動化為目的，**不提供任何投資建議**。

## 功能介紹

### 行情與監控清單
- **行情查詢**：支援上市、上櫃股票及 ETF，資料來自臺灣證券交易所基本市況報導網站。
- **新增股票**：輸入代號後按「查詢」，自動帶入股票名稱與目前價格。
- **編輯與刪除**：雙擊表格可編輯；按 Delete 鍵或右鍵選單可刪除，可一次選取多檔。
- **搜尋**：依股票名稱或代號篩選清單。
- **排序**：清單依未實現損益由大到小排列；沒有填股數的觀察股排在後面。
- **選填欄位**：停利目標價、低接提醒價可以留空，留空時顯示「-」。

### 儀表板
畫面上方四張資訊卡，只計算目前選取的清單：

| 資訊卡 | 內容 |
|---|---|
| 持股總市值 | 現價 × 股數的合計 |
| 未實現損益 | 合計損益與投資報酬率 |
| 今日損益 | 與前一交易日收盤相比的損益，以及清單平均漲跌 |
| 監控股票 | 總檔數，以及持股、觀察的檔數 |

漲跌顏色依台股慣例：紅漲綠跌。

### 多份 Excel 清單
- **每個 Excel 各自一份清單**：股數、成本、損益分開計算。同一檔股票出現在不同 Excel，會分別計算。
- **下拉選單切換**：右上角「切換清單」可選擇各個 Excel、「全部清單」或「手動新增」。
- **選項名稱**：取 Excel 檔名，並去掉「持股損益清單_股價更新_」開頭。例如 `持股損益清單_股價更新_元大.xlsx` 會顯示為「元大」。

### Excel 匯入
- **匯入方式**：可匯入單一檔案、一次多選，或匯入整個資料夾；也可以直接把檔案或資料夾拖進視窗。
- **讀取內容**：只讀取有股票代號的列；標題、空白列、小計等沒有代號的列會自動略過。
- **股數與成本**：Excel 若有股數、成本欄位會一併讀入；標題寫「張數」時，會自動乘以 1000 換算成股數。
- **代號確認**：匯入前會先向證交所確認代號存在，查不到的代號會略過並列出。
- **重新匯入**：Excel 內容修改後，可用「重新匯入」更新股數與成本；Excel 裡刪掉的股票會一併移除，資料夾中新加入的 Excel 也會被讀入。

### 股價寫回 Excel
- 匯入時，程式會把 Excel 複製一份到程式旁的 `stock` 資料夾（沒有會自動建立），**原始檔案不會被修改**。
- 每次更新行情後，只在副本中「有股票代號的列」寫入「最新股價」，其他欄位與格式都不會變動。
- 寫入時若副本正在 Excel 中開啟，程式左下角會顯示「無法寫入」；關閉 Excel 後按「立即更新」即可。

### 排程更新與通知
- **自動更新**：週一至週五 09:00–14:00，每 30 分鐘更新一次（09:00、09:30……14:00），週末不更新。
- **補抓**：程式較晚開啟時，只補抓最近的一個時段，不會把錯過的時段全部重抓。
- **失敗重試**：更新失敗時發出通知，5 分鐘後自動重試。
- **Windows 通知**：
  - 14:00 收盤報告
  - 價格提醒：達到停利價、跌破低接價，或漲跌幅超過警戒值（預設 ±5%，可調整）
  - 勾選「每次更新都跳通知」後，每 30 分鐘都會通知
- 同一檔股票的同一種提醒，一天只通知一次。

### 背景執行
- 按視窗右上角的 X 不會關閉程式，而是縮到右下角系統匣，排程照常執行。
- 在系統匣圖示上按右鍵，可開啟主視窗、立即更新或結束程式。
- 可勾選「開機自動啟動」，開機後自動在背景執行。
- 同一時間只會執行一個程式，重複開啟會提示程式已在執行中。

## Excel 格式說明

只有「股票代號」欄是必要的，其他欄位可有可無。範例：

| 股票代號 | 股票名稱 | 股數 | 成本均價 | 備註 |
|---|---|---|---|---|
| 2330 | 台積電 | 1000 | 2000 | 長期持有 |
| 0050 | | 2000 | 100 | |
| 6488 | 環球晶 | | | 觀察中 |

- **代號欄**：標題含「代號」、「代碼」、「code」等字樣即可辨識。沒有標題列時，程式會自動找出最像股票代號的那一欄。
- **股數欄**：標題含「股數」、「庫存」、「持股」、「張數」等字樣即可辨識。
- **成本欄**：標題含「成本」、「均價」、「買價」等字樣即可辨識。成本留空時，以第一次抓到的價格代入。
- **代號格式**：Excel 把 `0050` 顯示成 `50`，或代號寫成 `2330.TW`，程式都會自動修正。
- **支援的檔案格式**：`.xlsx`、`.xlsm`、`.csv`（UTF-8 或 Big5 編碼）。舊版 `.xls` 請先在 Excel 另存為 `.xlsx`。

## 安裝與執行

### 1. 下載專案

```bash
git clone https://github.com/royee0503/Python-Taiwan-Stock-Scrape
```

### 2. 進入專案資料夾

```bash
cd Python-Taiwan-Stock-Scrape
```

### 3. 安裝必要套件

```bash
pip install PyQt6 openpyxl
```

### 4. 執行程式

```bash
python Python_Stock_Monitor.py
```

若要直接在背景啟動（不開主視窗），可以使用：

```bash
pythonw Python_Stock_Monitor.py --minimized
```

## 打包成 exe

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed --name StockMonitor --hidden-import openpyxl Python_Stock_Monitor.py
```

打包完成後，執行檔位於 `dist\StockMonitor.exe`。如果有圖示檔，可以加上 `--icon stock_monitor.ico`。

**使用 exe 時請注意：**
- exe 請放在可以寫入的資料夾，例如 `D:\StockMonitor\`。不要放在 `C:\Program Files`（沒有寫入權限），也不建議放在 OneDrive 等雲端同步資料夾（可能與同步衝突，造成存檔失敗）。
- 第一次執行若出現「Windows 已保護您的電腦」，請按「其他資訊」→「仍要執行」。這是因為 exe 沒有數位簽章。
- exe 搬移位置後，請把「開機自動啟動」取消勾選再重新勾選一次。

## 資料存放位置

所有資料都存在程式（或 exe）所在的資料夾：

| 檔案 / 資料夾 | 內容 |
|---|---|
| `watchlist.json` | 監控清單、使用者設定、上次抓到的行情 |
| `stock\` | 寫回最新股價的 Excel 副本 |

建議定期備份這兩項。換電腦時，把它們複製到新的程式資料夾即可沿用；不過 `watchlist.json` 記錄的是舊電腦上的 Excel 路徑，換電腦後建議重新匯入一次 Excel。

## 常見問題

**Q：左下角顯示「無法寫入」？**
A：`stock` 資料夾中的 Excel 副本正在 Excel 裡開啟。關閉該檔案後按「立即更新」即可，下次排程也會自動重新寫入。

**Q：沒有出現 Windows 通知？**
A：請到 Windows「設定 → 系統 → 通知」確認通知已開啟，並關閉「勿擾」模式。可以先用左側的「測試通知」按鈕確認。

**Q：狀態顯示「查無資料」？**
A：該代號可能不是上市 / 上櫃股票（例如興櫃股票），或證交所網站暫時沒有回應。

**Q：09:00 那次的價格是昨天的收盤價？**
A：剛開盤時部分股票可能還沒有成交，程式會先顯示昨天的收盤價，下一次更新就會是當天價格。
